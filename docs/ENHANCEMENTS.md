## المرحلة 6: قياس الأثر المتقدم (Advanced Impact Measurement)

### 6.1 مقاييس بديلة (Altmetrics)
**ما هي؟** قياس أثر البحث خارج نطاق الاستشهادات الأكاديمية

| المقياس | المصدر | الوصف |
|---------|--------|-------|
| الذكر في وسائل التواصل | X/Twitter, LinkedIn, Reddit | عدد المشاركات والتفاعلات |
| التغطية الإخبارية | Altmetric API | ذكر البحث في وسائل الإعلام |
| ذكر في السياسات | Overton API | استخدام البحث في وثائق السياسات الحكومية |
| القراءات | Mendeley API | عدد القراء على Mendeley |
| الاستشهاد في براءات الاختراع | Lens.org API | استخدام البحث في براءات الاختراع |

**القيمة**: يثبت أن البحث له أثر مجتمعي وليس فقط أكاديمي — مهم جداً للتمويل والتصنيفات.

### 6.2 ربط الأبحاث بأهداف التنمية المستدامة (SDG Mapping)
**ما هي؟** تصنيف أبحاث المؤسسة حسب أهداف الأمم المتحدة الـ 17 للتنمية المستدامة

```
مثال:
بحث "تحلية المياه بالطاقة الشمسية"
  → SDG 6: المياه النظيفة
  → SDG 7: الطاقة النظيفة
  → SDG 13: العمل المناخي
```

| المكون | الوصف |
|--------|-------|
| تصنيف تلقائي بالذكاء الاصطناعي | تحليل العنوان والملخص وربطه بـ SDG |
| لوحة SDG | خريطة حرارية لتغطية كل هدف |
| تقارير SDG | للتصنيفات العالمية (QS, THE Impact Rankings) |
| مقارنة مؤسسية | مقارنة تغطية SDG مع جامعات أخرى |

**القيمة**: مطلوب لتصنيف THE Impact Rankings وكثير من جهات التمويل.

### 6.3 تطبيع الاستشهادات حسب المجال (Field-Normalized Citation Impact)
**المشكلة**: 50 استشهاد في الطب ≠ 50 استشهاد في الرياضيات

| المقياس | الوصف |
|---------|-------|
| FWCI (Field-Weighted Citation Impact) | نسبة الاستشهادات الفعلية للمتوقعة في المجال |
| CNCI (Category Normalized Citation Impact) | مقياس InCites المعادل |
| النسبة المئوية في المجال | ترتيب البحث ضمن أعلى 1%, 5%, 10% في مجاله |
| مؤشر التعاون الدولي | أثر التعاون على جودة البحث |

**القيمة**: مقارنة عادلة بين الأقسام والكليات المختلفة.

## المرحلة 17: كشف التلاعب البحثي والنزاهة الأكاديمية (Research Integrity & Fraud Detection)

> هذه المرحلة تحول النظام إلى **حارس نزاهة بحثية** يكشف الاستشهادات العائلية، السرقة العلمية، والنشر في مجلات مفترسة — بشكل تلقائي ومستمر

### 17.1 كشف الاستشهادات العائلية والتلاعب (Citation Manipulation Detection)

#### ما هي الاستشهادات العائلية (Family/Self-Citation)?
استشهاد متبادل بين مجموعة ثابتة من الباحثين لتضخيم h-index والاستشهادات بشكل مصطنع.

#### أنماط التلاعب التي يكشفها النظام

| النمط | الوصف | درجة الخطورة |
|-------|-------|-------------|
| **الاستشهاد الذاتي المفرط** | باحث يستشهد بنفسه بنسبة > 30% | متوسطة |
| **حلقة الاستشهاد (Citation Ring)** | مجموعة 3-10 باحثين يستشهدون ببعضهم بشكل متبادل فقط | **حرجة** |
| **الاستشهاد العائلي (Family Citation)** | استشهادات من نفس القسم/المجموعة البحثية بنسبة غير طبيعية | عالية |
| **تضخم مفاجئ** | قفزة غير مبررة في الاستشهادات خلال فترة قصيرة | عالية |
| **استشهاد غير ذي صلة** | استشهاد من أبحاث في مجال مختلف تماماً | متوسطة |
| **الاستشهاد القسري (Coercive Citation)** | محرر مجلة يطلب الاستشهاد بمجلته كشرط للنشر | عالية |
| **Citation Stacking** | مجلة ترتفع استشهاداتها فجأة من مصدر واحد | **حرجة** |

#### محرك التحليل (Citation Analysis Engine)

```
تدفق التحليل:
                                    
  ┌──────────────┐    ┌─────────────────┐    ┌──────────────────┐
  │ جمع بيانات   │───→│ بناء شبكة       │───→│ تحليل الأنماط    │
  │ الاستشهادات  │    │ الاستشهادات     │    │ المشبوهة         │
  └──────────────┘    └─────────────────┘    └────────┬─────────┘
                                                       │
  ┌──────────────┐    ┌─────────────────┐    ┌────────▼─────────┐
  │ تقرير        │←───│ تقييم AI        │←───│ حساب مؤشرات     │
  │ النزاهة      │    │ (DeepSeek)      │    │ الخطورة          │
  └──────────────┘    └─────────────────┘    └──────────────────┘
```

#### المؤشرات الحسابية

| المؤشر | الحساب | العتبة المشبوهة |
|--------|--------|-----------------|
| **نسبة الاستشهاد الذاتي** | استشهادات ذاتية / إجمالي الاستشهادات | > 25% |
| **مؤشر التبادل (Reciprocity Index)** | (A يستشهد بـ B + B يستشهد بـ A) / إجمالي | > 40% بين باحثين |
| **مؤشر التجمع (Clustering Coefficient)** | كثافة الاستشهاد داخل مجموعة مغلقة | > 60% |
| **مؤشر التنوع (Diversity Index)** | عدد المصادر الفريدة / إجمالي الاستشهادات | < 0.3 |
| **معدل النمو الشاذ** | (استشهادات هذا الشهر - المتوسط) / الانحراف المعياري | z-score > 3 |
| **h-index مُنقح** | h-index بعد حذف الاستشهادات الذاتية والعائلية | الفرق > 30% من الأصلي |
| **نسبة الاستشهاد من نفس المؤسسة** | استشهادات من نفس الجامعة / الإجمالي | > 35% |
| **عمر الاستشهاد** | متوسط عمر الأبحاث المُستشهد بها | < 1 سنة بشكل متكرر (مشبوه) |

#### رسم بياني لشبكة الاستشهادات (Citation Network Graph)
```

  باحث A ●━━━━━━━━━● باحث B
           ╲  🔴    ╱
            ╲      ╱
             ╲    ╱
              ╲  ╱
               ●
           باحث C

```

### 17.2 كشف السرقة العلمية والانتحال (Plagiarism Detection)

#### مستويات الكشف

| المستوى | الأداة | ما يكشفه |
|---------|--------|---------|
| **1. انتحال النص** | Turnitin/iThenticate API | نسخ نص حرفي أو معاد صياغته |
| **2. انتحال الأفكار** | DeepSeek AI | نفس المنهجية/النتائج بصياغة مختلفة |
| **3. الانتحال الذاتي** | تحليل داخلي | الباحث ينشر نفس البحث عدة مرات |
| **4. انتحال البيانات** | تحليل إحصائي | بيانات مُفبركة أو مُعاد تدويرها |
| **5. انتحال الصور** | تحليل صور | صور مُعدلة أو مُعاد استخدامها |

#### نظام كشف الانتحال الذاتي (Self-Plagiarism / Salami Slicing)

```
تحليل "تقطيع السلامي" (Salami Slicing):

بحث أصلي: "تأثير X على Y في البيئة Z"
    ↓ تقطيع مشبوه:
    ├── بحث 1: "تأثير X على Y" (نفس البيانات، بيئة محذوفة)
    ├── بحث 2: "دراسة Y في البيئة Z" (نفس البيانات، X محذوف)  
    └── بحث 3: "العلاقة بين X و Z" (نفس البيانات، زاوية مختلفة)
```

| المؤشر | الطريقة |
|--------|---------|
| **تشابه العناوين** | Semantic similarity > 0.75 بين أبحاث نفس الباحث |
| **تشابه الملخصات** | TF-IDF + Cosine similarity > 0.60 |
| **تطابق المؤلفين** | نفس قائمة المؤلفين بترتيب مختلف |
| **تكرار البيانات** | نفس حجم العينة، نفس النتائج الإحصائية |
| **إعادة النشر** | نفس البحث في مجلة مختلفة |

#### تحليل DeepSeek للانتحال
```
المدخلات لـ DeepSeek:
{
  "task": "plagiarism_analysis",
  "publication_1": { "title": "...", "abstract": "...", "methodology": "..." },
  "publication_2": { "title": "...", "abstract": "...", "methodology": "..." },
  "same_author": true
}

المخرجات:
{
  "similarity_score": 0.82,
  "type": "self_plagiarism_salami_slicing",
  "evidence": [
    "نفس المنهجية مع تغيير طفيف في المتغيرات",
    "87% من الجداول تحتوي بيانات متطابقة",
    "الملخص معاد صياغته بنسبة 70%"
  ],
  "severity": "high",
  "recommendation_ar": "يُحتمل تقطيع سلامي — يُنصح بمراجعة أخلاقية"
}
```

### 17.3 كشف المجلات المفترسة والنشر السيء (Predatory Publishing Detection)

#### ما هو النشر المفترس؟
مجلات تدّعي التحكيم العلمي لكنها تنشر أي شيء مقابل رسوم، بدون مراجعة حقيقية.

#### قاعدة بيانات المجلات المفترسة

| المصدر | الوصف | التحديث |
|--------|-------|---------|
| **Beall's List** | قائمة Jeffrey Beall للناشرين المفترسين | ربع سنوي |
| **Cabells Predatory Reports** | قاعدة بيانات تجارية شاملة (800+ معيار) | شهري |
| **DOAJ** | Directory of Open Access Journals (القائمة البيضاء) | مستمر |
| **JCR / Scopus** | المجلات المفهرسة (القائمة البيضاء) | سنوي |
| **Retraction Watch** | قاعدة بيانات الأبحاث المسحوبة | مستمر |

#### مؤشرات المجلة المفترسة (Predatory Journal Indicators)

| المؤشر | الوصف | الوزن |
|--------|-------|-------|
| **غير مفهرسة** | ليست في Scopus أو Web of Science أو DOAJ | **30%** |
| **في قائمة Beall** | مُدرجة في قوائم المجلات المفترسة | **25%** |
| **Impact Factor مزيف** | تدّعي IF غير موجود في JCR | **15%** |
| **مراجعة سريعة جداً** | قبول خلال أقل من أسبوع | **10%** |
| **رسوم APC مبهمة** | رسوم نشر غير واضحة أو مرتفعة جداً | **5%** |
| **هيئة تحرير وهمية** | أعضاء غير حقيقيين أو بدون خبرة | **5%** |
| **بريد عام** | تستخدم Gmail/Yahoo بدلاً من بريد مؤسسي | **3%** |
| **إرسال عشوائي** | ترسل دعوات نشر عشوائية (spam) | **3%** |
| **عنوان عام** | اسم عام جداً (International Journal of...) | **2%** |
| **موقع رديء** | أخطاء إملائية، تصميم غير احترافي | **2%** |

#### نظام التقييم التلقائي للمجلات

```
تصنيف المجلات:

🟢 آمنة (Safe)         — درجة 0-20  — مفهرسة في Scopus/WoS/DOAJ
🟡 تحتاج مراجعة       — درجة 21-50 — بعض العلامات التحذيرية
🟠 مشبوهة (Suspicious) — درجة 51-75 — علامات متعددة
🔴 مفترسة (Predatory)  — درجة 76-100 — مؤكدة أو شبه مؤكدة

مثال:
"International Journal of Advanced Research" 
├── غير مفهرسة في Scopus ✗ (+30)
├── في قائمة Beall ✗ (+25)  
├── تدعي IF 5.2 غير موجود في JCR ✗ (+15)
├── قبول خلال 3 أيام ✗ (+10)
├── بريد Gmail ✗ (+3)
└── الدرجة: 83/100 → 🔴 مفترسة
```

#### تحليل النشر السيء على مستوى الباحث

| المقياس | الوصف |
|---------|-------|
| **نسبة النشر المفترس** | أبحاث في مجلات مفترسة / إجمالي الأبحاث |
| **اتجاه النشر** | هل يتحسن أم يسوء اختيار المجلات مع الوقت؟ |
| **مقارنة بالأقران** | مقارنة جودة المجلات مع باحثين في نفس المجال |
| **h-index المُنقح** | h-index بعد حذف الأبحاث في مجلات مفترسة |
| **تنبيه استباقي** | تحذير الباحث قبل التقديم لمجلة مشبوهة |

#### تحليل على مستوى المؤسسة

```
لوحة النشر المفترس المؤسسية:

إجمالي الأبحاث: 2,450
├── 🟢 في مجلات آمنة: 2,100 (85.7%)
├── 🟡 تحتاج مراجعة: 180 (7.3%)
├── 🟠 في مجلات مشبوهة: 120 (4.9%)
└── 🔴 في مجلات مفترسة: 50 (2.0%)

الأقسام الأكثر نشراً في مجلات مشبوهة:
1. قسم ___: 15 بحث (8.2% من أبحاثهم)
2. قسم ___: 12 بحث (6.1%)
3. قسم ___: 8 أبحاث (4.5%)

الاتجاه السنوي:
2023: 4.5% مفترس → 2024: 3.2% → 2025: 2.0% ✅ تحسن
```

### 17.5 سير عمل المراجعة والتحقيق (Review & Investigation Workflow)

```

  اكتشاف تلقائي          مراجعة أولية          تحقيق            قرار

  │ النظام   │────────→│ مسؤول        │────→│ لجنة      │───→│ إجراء    │
  │ يكتشف   │         │ النزاهة      │     │ التحقيق   │    │ تأديبي   │

  └──────────┘         └──────┬───────┘     └───────────┘    └──────────┘
                              │
                    ┌─────────▼─────────┐
                    │ إيجابي كاذب؟      │
                    │ نعم → إغلاق       │
                    │ لا → تصعيد        │
                    └───────────────────┘
```

| المتابعة | النظام | مستمر | مراقبة دورية |
